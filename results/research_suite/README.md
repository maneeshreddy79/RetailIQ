# RetailIQ V1.0 Research Suite Results

These results correspond to the corrected V1.0 methodology.

- 12 datasets
- 5 classification
- 2 regression
- 3 unsupervised
- 1 anomaly-detection benchmark with ground truth
- 1 temporal forecasting benchmark
- General supervised evaluation: 5 repeats × 5 folds
- Primary classification metric: weighted F1
- Primary regression metric: RMSE
- Statistical tests: Friedman followed by Wilcoxon with Holm correction when applicable
- Reference/ground-truth labels are excluded from unsupervised model inputs.
- Temporal forecasting uses chronological holdout evaluation.

The interactive app can regenerate the complete suite with the same protocol using the Expanded Research Suite control.
