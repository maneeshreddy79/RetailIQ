# RetailIQ V1.0 Advanced ML Methodology

RetailIQ V1.0 evaluates additional predictive and analytical paths while keeping the system transparent and reproducible.

## Validation
General tabular supervised tasks use leakage-safe repeated cross-validation in the research suite (5 repeats × 5 folds). Interactive temporal datasets use chronological holdout validation when a date-like column is detected. Forecasting uses a historical training window and a future holdout.

## Models
- Logistic Regression, Decision Tree, Random Forest, Gradient Boosting for classification.
- Linear Regression, Decision Tree, Random Forest, Gradient Boosting for regression.
- K-Means for unsupervised clustering.
- Isolation Forest for anomaly detection.
- Ridge lag model and Gradient Boosting lag model for forecasting.

## Ground-truth labels
Explicit reference fields such as `is_anomaly`, `anomaly_label`, `ground_truth`, and `outlier_label` are excluded from unsupervised model inputs. When a valid binary reference label exists, anomaly predictions are evaluated independently with precision, recall and F1.

## Recommendations
ML-guided recommendations compare measured advanced-model performance with the best baseline under the same validation setup. An advanced model is not described as superior when its metric is worse. Forecast recommendations include the selected model, horizon and projected change and are framed as evidence requiring review rather than certainty.

## Interpretation
Permutation importance describes predictive contribution on the evaluated data; it is not causal evidence. Automated narrative insights are deterministic and data-grounded rather than generated by an external LLM.
